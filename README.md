# مخزن الملابس: دليل التشغيل

برنامج ويب خاص بك: خادم صغير + واجهة عربية. بدون أي مكتبات خارجية، يحتاج فقط **Node.js 18 أو أحدث**: https://nodejs.org

## التشغيل على جهاز في المحل (الأسهل)
1. ثبّت Node.js على أي حاسوب يبقى شغالاً.
2. فك الضغط ثم انقر مرتين على `start.bat` (على ماك/لينكس: `node server.js`).
3. افتح http://localhost:3000 وأنشئ حساب المسؤول الرئيسي (أول تشغيل فقط).
4. الموظفون على نفس شبكة الواي فاي يفتحون `http://عنوان-الحاسوب:3000`
   (اعرف العنوان بالأمر `ipconfig`، وابحث عن IPv4 مثل 192.168.1.20).
   قد يطلب ويندوز السماح للبرنامج بالشبكة: اضغط «سماح».

## التشغيل على الإنترنت (ليدخل الموظفون من أي مكان)
- أي استضافة تشغّل Node.js: Render، Railway، Fly.io، أو سيرفر VPS: الأمر `node server.js`.
- **مهم:** اجعل مجلد البيانات على قرص دائم، وأعطِ المتغير `DATA_DIR` مساره. الاستضافات المجانية بدون قرص دائم تمسح البيانات عند كل إعادة تشغيل.
- فعّل HTTPS (توفره هذه الاستضافات تلقائياً)، لأن كلمات المرور تُرسل عبر الشبكة.
- المتغير `PORT` تحدده الاستضافة تلقائياً.

## المستخدمون والصلاحيات (من داخل البرنامج)
- **مسؤول:** يضيف ويعدّل كل شيء (الأسكفات والأعمدة والرفوف والصناديق والمنتجات) ويدير المستخدمين من تبويب «المستخدمون».
- **عامل:** بحث فقط، والخادم يرفض أي تعديل منه حتى لو حاول.
- المسؤول يضيف العمال والمسؤولين الآخرين ويرقّيهم ويغيّر كلمات مرورهم ويحذفهم. لا يمكن حذف آخر مسؤول.

## البيانات والنسخ الاحتياطي
- كل شيء في مجلد `data` (`data.json` للمخزن، `users.json` للمستخدمين). انسخ المجلد بانتظام.
- تبويب «النسخ» يصدّر/يستعيد المخزن كنص.


## النشر على Render مع حفظ البيانات
هذا المشروع مجهّز بملف `render.yaml`. عند إنشاء Blueprint في Render سيُنشأ خادم Node.js مع قرص دائم 1GB، ويُحفظ `data.json` و`users.json` داخل `/var/data`.
**ملاحظة:** القرص الدائم في Render يتطلب خدمة مدفوعة (Starter أو أعلى). لا تستخدم استضافة مجانية بقرص مؤقت إذا كنت تريد الاحتفاظ بالبيانات بعد إعادة التشغيل أو النشر.
